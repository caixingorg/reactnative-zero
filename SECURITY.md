# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Use GitHub's private vulnerability reporting instead: open the **Security** tab of this
repository and choose **Report a vulnerability**. Include the affected version, steps to
reproduce, and the impact you observed.

You can expect an acknowledgement within a few days. Fixes are released as soon as a
patch is available, and reporters are credited unless they ask not to be.

## Scope

This repository is an application template. It deliberately contains no credentials,
signing keys, API tokens or production endpoints. If you find any of these committed,
please report it through the channel above.
