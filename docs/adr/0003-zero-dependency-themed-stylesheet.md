# Use Zero-Dependency Themed StyleSheet Primitives Instead of Compile-Time Styling Libraries

We build UI styling on React Native's built-in `StyleSheet.create`, paired with semantic Design Tokens and lightweight typed layout primitives (`Box`, `Stack`, `AppText`), rather than adopting `NativeWind`, `Unistyles`, `Tamagui`, or `@shopify/restyle`. Compile-time and runtime-interop styling layers (`NativeWind`'s Metro/Babel JSX pipeline and `cssInterop` wrapper, or C++ Nitro bindings in `Unistyles`) repeatedly introduce upgrade friction across major Expo/React Native releases and frame-drop overhead in heavy lists, while `@shopify/restyle` has been archived upstream. Owning a thin (~100-line) typed token and primitive layer eliminates external styling lock-in and guarantees zero-breakage framework upgrades across all derived App Instances.
